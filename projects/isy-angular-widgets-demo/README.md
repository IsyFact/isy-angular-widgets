Die Demo-Anwendung demonstriert die Widgets aus `projects/isy-angular-widgets` und bindet diese direkt aus dem Quellcode ein. Sie ist nicht Bestandteil des veröffentlichten npm-Pakets.

Dieser Branch pflegt die Versionslinie 21; die zugehörige Demo wird unter <https://isyfact.github.io/isy-angular-widgets/v21/> veröffentlicht.

## Funktionen

Die Anwendung erfüllt derzeit vier Zwecke:

1. **Lokales Testen** im Rahmen von Weiterentwicklung und Wartung der Bibliothek.
2. **Bereitstellung als GitHub Page** für Demonstrationen und fachliche Abnahmen.
3. **Darstellung von Komponenten und Konzepten aus dem [IsyFact-Bedienkonzept](https://isyfact.github.io/isy-bedienkonzept-doc/current/bedienkonzept.html)** am fachlichen Beispiel der Planung und Koordination der verfahrensbezogenen Transition.
4. **Optische Demonstration der meisten PrimeNG-Komponenten** mit dem IsyFact-Theme.

## Lokal starten

```bash
npm start
```

Das vollständige Entwicklungs-Setup beschreibt die [README im Repository-Root](../../README.md).
